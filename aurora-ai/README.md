# SJ Portfolio

A modern, responsive personal portfolio developed by **Shaik Jareena** using Next.js, React, TypeScript, Tailwind CSS, Framer Motion, and Three.js.

The portfolio showcases my software-engineering background, project leadership experience, technical skills, certifications, projects, and interest in remote Project Manager and Operations Manager opportunities.

## Live Portfolio

[View the live portfolio](https://aurora-ai-portfolio.vercel.app)

## Key Features

- Responsive design for mobile, tablet, and desktop
- Interactive 3D Earth built with React Three Fiber
- Smooth animations using Framer Motion
- Animated role-typing effect
- Professional experience timeline
- Categorized technical and leadership skills
- Featured project cards with screenshots
- Certifications and professional learning section
- Working contact form powered by Formspree
- Resume download
- Mobile navigation menu
- Active navigation-section highlighting
- SEO metadata
- Automatic deployment through Vercel

## Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/JAREENA-SK/aurora-ai-portfolio.git
```

### 2. Open the application folder

```bash
cd aurora-ai-portfolio/aurora-ai
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## Production Build

```bash
npm run build
```

The project uses Webpack for local development and production builds because Windows Application Control blocks the native SWC binding on the development machine.
